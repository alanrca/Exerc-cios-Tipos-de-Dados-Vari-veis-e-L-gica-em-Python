# 📊 Python – Prática de Fundamentos para Análise de Dados

## 📌 Sobre o Projeto

Este repositório tem como objetivo **documentar e consolidar a prática dos fundamentos de Python**, com foco em **análise de dados aplicada a negócios**.

Os exercícios aqui desenvolvidos fazem parte de um processo estruturado de aprendizado, cujo propósito é **fortalecer a base lógica**, compreender o uso correto dos **tipos de dados**, aplicar **operações matemáticas e lógicas**, além de adotar **boas práticas de escrita de código** alinhadas ao mercado.

Este material representa uma etapa fundamental de preparação antes do uso de bibliotecas mais avançadas, como `pandas`, e da aplicação de Python em cenários reais de BI, análise exploratória e automação de relatórios.

---

## 🎯 Objetivos de Aprendizado

* Consolidar o uso correto de **variáveis e tipos de dados**
* Praticar **operações matemáticas e lógicas**
* Trabalhar com **estruturas de dados** (listas, tuplas e dicionários)
* Desenvolver **lógica condicional** aplicada a regras de negócio
* Simular cenários comuns de **análise de dados corporativos**
* Aplicar **boas práticas de código** (legibilidade, nomenclatura e clareza)

---

## 🧠 Conteúdos Praticados

Os exercícios estão organizados de forma progressiva, abordando:

### 🔹 Tipos de Dados e Variáveis

* `int`, `float`, `str`, `bool`
* Contextos de uso em negócios
* Formatação de strings (`f-strings`)

### 🔹 Operações Matemáticas e Conversões

* Cálculo de métricas (receita, média, crescimento)
* Conversão de dados oriundos de planilhas (`str → int / float`)

### 🔹 Lógica Condicional

* Estruturas `if`, `elif`, `else`
* Operadores lógicos (`and`, `or`)
* Regras de classificação e segmentação

### 🔹 Estruturas de Dados

* **Listas**: agregações, médias, máximos e mínimos
* **Tuplas**: dados fixos e imutáveis
* **Dicionários**: representação de entidades de negócio
* **Listas de dicionários**: simulação de tabelas e registros

---

## 📊 Contexto de Negócio

Todos os exercícios utilizam exemplos práticos inspirados em cenários reais, como:

* Análise de faturamento
* Metas de vendas
* Segmentação e score de clientes
* Controle de estoque
* Indicadores simples de performance

O foco está em **pensar como analista de dados**, não apenas em escrever código.
